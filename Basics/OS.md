# Operating System
This is a software that runs on top of hardware or bare metal given to us. Like a keyboard, memory, CPU etc are accessible only if we install Operating system on it.
It makes it easier for the user to interact with these resources, helps to utilize them to maximum extent.

On top of bare metal Kernel is present which talks to hardware which runs in kernel mode such that it has access to all the resources.
Above kernel lies our Shell (bash, sh, zsh, etc) from which user gives commands to make system calls to kernel.
